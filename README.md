# Classificador de nível de herói

Exercício de lógica que classifica personagens de acordo com sua quantidade de experiência.

## 📌 Funcionalidades

- Percorre uma lista de heróis.
- Define o nível com base no XP.
- Exibe o nome e o nível de cada personagem.

## Tecnologias

JavaScript e Node.js.

## 🚀 Como executar

```bash
git clone https://github.com/daviddevdias/hero-level-classifier.git
cd hero-level-classifier
node desafioDosHerois.js
```

Edite a lista em `desafioDosHerois.js` para experimentar outros nomes e valores de XP.
